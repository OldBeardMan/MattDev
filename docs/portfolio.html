Celem projektu było zebranie w jednym miejscu pełnej informacji o firmie: danych kontaktowych, obszaru działalności, zakresu usług, najczęściej zadawanych pytań oraz opinii klientów. Mind of Seasons

  • Gra 2D Szukanie zagubionych kotków
  • System zapisu Generowany świat
  • System audio i efekty dźwiękowe Interfejs użytkownika
  • Python / Pygame

Mind of Seasons to autorska gra 2D napisana w języku Python z wykorzystaniem biblioteki Pygame. Projekt obejmuje proceduralną generację świata, pełny system zapisu i odczytu stanu gry, rozbudowany interfejs użytkownika, system audio z generatorem efektów dźwiękowych oraz system NPC. Jest to najbardziej złożony z moich projektów autorskich pod względem architektury kodu.

Vibe Tuner

  • Wykrywanie emocji ze zdjęcia twarzy Dobór muzyki do emocji
  • Historia emocji Analityka emocji w czasie
  • Python Praca inżynierska - Politechnika Lubelska

Vibe Tuner to aplikacja, którą wykonałem jako pracę inżynierską na Politechnice Lubelskiej. Na podstawie zdjęcia twarzy rozpoznaje emocje użytkownika i automatycznie dobiera do nich odpowiednią muzykę. Aplikacja zapisuje historię wykrytych emocji i udostępnia moduł analityczny, który pokazuje, jak nastrój zmieniał się w czasie.
